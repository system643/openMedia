# Tâche : écrire pour l'oreille

Réécris la fiche d'actualité reçue pour qu'elle soit écoutée : environ deux minutes, phrases courtes, aucune parenthèse, aucune abréviation, aucune référence `S…`, les sources nommées à l'oral (« selon l'AFP »), les chiffres arrondis et écrits comme on les dit. Commence par l'essentiel, puis les nouveautés, puis ce qui reste incertain et ce qui est attendu. Rends uniquement le texte à lire, sans titre ni indication de mise en scène.
